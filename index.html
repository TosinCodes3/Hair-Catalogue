Supabase
Backend for your haircut library
Setup guide
1
Go to supabase.com → create a project → wait for it to finish provisioning
2
In SQL Editor, run this all at once:

create table if not exists haircuts (id uuid default gen_random_uuid() primary key, name text not null, description text, category text, hair_type text, tags text[], images jsonb, before_image text, after_image text, created_at timestamptz default now()); alter table haircuts enable row level security; create policy "Allow all" on haircuts for all using (true) with check (true); -- If table already exists, run these instead: -- alter table haircuts add column if not exists before_image text; -- alter table haircuts add column if not exists after_image text;
3
Go to Storage → New bucket → name it exactly haircut-images → tick Public bucket → Create

Then in Storage → Policies → Add policy → choose "Give users access to a folder only to authenticated users" — or simply run:

create policy "Public access" on storage.objects for all using (bucket_id = 'haircut-images') with check (bucket_id = 'haircut-images');
4
Go to Project Settings → API → copy Project URL and anon / public key into the fields below
Found in Project Settings → API → Project URL
Found in Project Settings → API → Project API Keys → anon public

Annotator Guide
Drawing Tools
Freehand
Draw freely with your finger — any shape or scribble.
Straight Line
Drag from start to end to draw a clean solid straight line.
Arrow
Drag to draw a straight line with an arrowhead at the end.
Curve
Two gestures: first drag sets the chord (start to end), second drag bends it into a smooth arc.
Dashed Line
Drag to draw a dashed straight line — useful for guides or measurements.
Actions
Select Haircut
Open your uploaded haircuts and load one as the background to annotate on.
Undo
Remove the last stroke you drew, one step at a time.
Redo
Restore a stroke you just undid.
Clear
Erase all drawings from the canvas in one go.
Export
Save the annotated haircut photo (drawing + image) as a PNG to your device.
Colours & Size
Colour Dots
Tap any colour dot in the toolbar to switch the stroke colour.
S / M / L
Sets the stroke thickness — Small, Medium, or Large.
